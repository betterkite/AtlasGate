# Web Clipper Boundary

URL ingest is implemented through lightweight HTML-to-text extraction in the Wiki compiler. A browser extension is not part of the current core product.

The optional future Web Clipper should:

- capture article text and metadata into an immutable raw source;
- preserve the source URL and capture time;
- download or retain referenced assets when licensing permits;
- send content through the existing ingest, Review, Change, and publication lifecycle;
- never write directly to the Master or trust a client-provided server path.

DOCX, XLSX, EPUB, OCR, and full browser extension workflows remain optional follow-up capabilities.
