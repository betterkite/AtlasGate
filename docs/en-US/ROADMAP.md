# Roadmap

## Delivered foundation

- Multi-protocol gateway, routing, quotas, balances, and audit.
- Versioned knowledge Changes, atomic Master publication, conflicts, tombstones, and historical retrieval.
- Raw source ledger, persistent ingest queue, LLM Wiki compilation, Review, Lint, graph, sync, and ZIP export.
- Python Agent pool, Memory, Skills, local/hybrid retrieval, and MCP.

## Next priorities

- Append-only raw-source re-ingest history and stronger generation lineage.
- Schema/purpose context in Agent query prompts with versioned prompt evidence.
- Human approval gates and domain-specific merge functions for high-risk bases.
- OCR and optional DOCX/XLSX/EPUB parsing.
- Public administrator identity, CSRF, TLS integration, and stronger Provider egress controls.
- Distributed storage and service decomposition only when operational scale justifies it.
